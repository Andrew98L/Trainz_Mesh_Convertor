# Trainz Mesh Convertor

Программа на Python, предназначенная для конвертации проприетарного формата 3D-геометрии `.trainzmesh`, используемого в играх Trainz Railroading Simulator, в OBJ.

Инструмент разработан для помощи авторам контента в восстановлении геометрии утерянных исходников.

## Основные возможности
* Чтение и парсинг внутренних бинарных блоков файлов `.trainzmesh`.
* Извлечение данных о вершинах (vertices), индексах (indices) и текстурных координатах (UV).
* Экспорт геометрии в формат OBJ, совместимый с современными 3D-редакторами (например, Blender).

## Системные требования
Для работы скрипта необходим установленный интерпретатор **Python 3.x**.

## Как использовать
В папке, в которой находится файл программы и 3D-модели, откройте консоль и выполните в ней команду:
```bash
python convertor.py name_of_model.trainzmesh
```
